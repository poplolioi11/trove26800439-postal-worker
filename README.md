# 郵役發狂（《東華報》1904-05-21 第3版，澳洲國家圖書館） / You yi fa kuang [A Postal Worker Reported to Have Become Insane]: Transcription Dataset

《東華報》1904-05-21 刊載的〈郵役發狂〉。報載雪梨郵役在工作時行為驟變，主管勸解後請巡差介入。記事同載一名受傷巡差入院及郵役被押往監房。

You yi fa kuang [A Postal Worker Reported to Have Become Insane] appeared in Tung Wah Times (1904-05-21). A Sydney report records a postal supervisor's response after a postal worker behaved unusually at work. The account follows police intervention, a constable admitted to hospital, and the detention of the worker.

TXT, JSON and TEI XML cover the complete separately headed article, comprising the heading and 13 source columns on page 3. An independent image reading was compared with the first transcription. Source-image adjudication adopted 1 changes and retained unresolved readings.

## 方法與覆核 / Methods and review

由 AI 依固定館方影像逐欄讀字，保留原字、版面與疑讀。照錄原題、時代用字與原欄次。疑讀按欄記在 JSON。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant transcribed the fixed source images column by column, preserving source forms, layout and uncertain readings. Headings, historical terminology and source column order are preserved. Uncertainties are recorded by column. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
